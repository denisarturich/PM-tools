## 📦 Созданные файлы

### 1. `clean-git-history.sh` ✅
Основной скрипт для очистки истории. Поддерживает:
- Удаление конкретных файлов
- Замену паролей на ***REMOVED***
- Удаление всех .env файлов
- Комплексную очистку

**Использование:**
```bash
./clean-git-history.sh
```

### 2. `GIT_SECURITY_GUIDE.md` 📚
Полное руководство по безопасности Git:
- Пошаговые инструкции
- Методы очистки
- Предотвращение будущих утечек
- FAQ и решение проблем

### 3. `setup-git-hooks.sh` 🛡️
Устанавливает pre-commit хук для предотвращения будущих утечек.

**Использование:**
```bash
./setup-git-hooks.sh
```

Будет проверять каждый коммит на:
- .env файлы
- Приватные ключи (.pem, .key, id_rsa)
- Пароли и API ключи в коде

### 4. `replacements.txt.example` 📝
Пример файла для замены конкретных паролей в истории.

**Использование:**
```bash
# Скопировать пример
cp replacements.txt.example replacements.txt

# Отредактировать, добавив свои пароли
nano replacements.txt

# Запустить замену
git filter-repo --replace-text replacements.txt --force
```

## 📞 Быстрая справка

### Команды для экстренной очистки

```bash
# Удалить файл из истории
git filter-repo --path .env --invert-paths --force

# Заменить пароль во всей истории
echo "old_password==>***REMOVED***" > replacements.txt
git filter-repo --replace-text replacements.txt --force

# Очистить локальные ссылки
git reflog expire --expire=now --all
git gc --prune=now --aggressive
```

### После очистки

```bash
# Проверить историю
git log --all --oneline

# Отправить изменения (FORCE)
git push origin --force --all
git push origin --force --tags
```
